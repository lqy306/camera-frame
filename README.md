# Camera Frame

Camera Frame 是一款面向 iPhone Safari 的离线优先照片拼图 PWA。用户选择一张照片后，应用会把它同时放入固定相机的液晶屏和成片区域，并根据照片主色自动生成相机周围的背景。

在线地址：<https://syjjsy.github.io/camera-frame/>

> GitHub 仓库是私有仓库，但 GitHub Pages 网站本身是公开地址，知道网址的人都可以使用和安装。此 Pages 版本不包含共享密码。原有密码网站及其本地项目不受此仓库影响。

## 主要功能

- 两种构图：上下结构适合横版照片，左右结构适合标准 2:3 竖版照片。
- 五种相机模板：Ricoh GR II、Sony A7C II、Nikon Zf、SIGMA BF、LUMIX S1RM2。
- 相机机身、按钮、文字和屏幕边框保持固定，只替换 LCD 内容。
- 纯色全替换、柔和渐变、原版轻度融合三种背景模式。
- 自动提取 3–5 个候选综合色，也可手动选择背景色。
- 支持 cover / contain、拖动构图、双指缩放、LCD 与成片同步。
- JPG / PNG 保存以及 iPhone 系统分享。
- JPG、JPEG、PNG、WEBP、EXIF 方向和透明 PNG。
- 计算在设备本地完成；选择的照片不会上传到服务器。
- 首次在线完整加载后，可从主屏幕离线打开和合成照片。

## iPhone 安装

首次安装必须联网，并建议直接使用 Safari，不要在微信或其他应用内置浏览器中操作。

1. 在 iPhone Safari 打开 <https://syjjsy.github.io/camera-frame/>。
2. 等待页面显示模板已经加载完成，并确认五种相机模板可以选择。
3. 点击 Safari 工具栏的“分享”按钮。
4. 在分享菜单中向下滚动，选择“添加到主屏幕”。
5. 名称保留为 Camera Frame，点击右上角“添加”。
6. 回到主屏幕，从 Camera Frame 图标启动一次。
7. 保持联网，选择一张照片并成功生成一次预览，使程序资源完整进入离线缓存。

完成以上步骤后，出门没有网络时仍可从主屏幕打开应用、选择本机照片、合成并保存。首次加载、程序更新或清除 Safari 网站数据后，需要重新联网缓存。

## iPhone 操作

1. 点击“选择照片”，从照片图库选取一张图。
2. 在“相机模板”中选择 Ricoh GR II、Sony A7C II、Nikon Zf、SIGMA BF 或 LUMIX S1RM2。
3. 横版照片选择“上下结构 · 横版照片”；竖版照片选择“左右结构 · 竖版照片”。
4. 默认使用“纯色全替换”，程序会从照片自动取色。点击候选色块可立即换色，也可手动选色。
5. 需要调整构图时，开启“在预览上拖动构图”，单指拖动、双指缩放。默认 LCD 与成片使用同一构图。
6. 在参数区调整背景饱和度、亮度、纹理、阴影以及 LCD 亮度、饱和度和对比度。
7. 选择 JPG 或 PNG，点击“保存图片”；也可以点击“分享”发送到相册或其他应用。
8. 如果 Safari 显示“打开图片”，打开生成图后长按图片，再选择“存储到照片”。

横图推荐上下结构，竖图推荐左右结构。应用始终保持输入照片宽高比，不会拉伸变形。

## 离线使用与更新

- 离线可用的前提是曾在联网状态下完整打开当前版本。
- 可用飞行模式测试：关闭应用，开启飞行模式，再从主屏幕图标启动。
- 发布新版本后，iPhone 联网打开应用并停留数秒，然后完全退出并重新打开。
- 若始终加载旧版，可在“设置 → Safari → 高级 → 网站数据”中删除本网站数据，再联网访问并重新添加到主屏幕。
- 删除 Safari 网站数据会一并清除离线缓存；用户原始照片不会存储在网站中。

## 本地开发

需要 Node.js 18 或更高版本：

```bash
git clone https://github.com/syjjsy/camera-frame.git
cd camera-frame
npm ci
npm run dev
```

常用命令：

```bash
npm test
npm run build
npm run test:browser
npm run test:pwa
```

也可在 macOS Finder 中双击 `start.command`。局域网 HTTP 适合功能调试；iPhone 安装、Service Worker 离线缓存和完整分享能力应使用正式 HTTPS 地址。

## 固定版式

- 上下画布：1280 × 1813，上下分界 y = 960。
- 左右画布：2720 × 1920。
- 左侧竖版照片区：1280 × 1920，比例为 2:3。
- 右侧相机区：1440 × 1920。
- 每个相机模板分别使用独立的透明机身、阴影、屏幕蒙版和 LCD 明暗层。

合成顺序为：综合色背景、独立相机阴影、固定透明机身、替换后的 LCD 画面、同源成片。背景变色不会染入相机机身，下方或左侧照片不参与综合色修改。
